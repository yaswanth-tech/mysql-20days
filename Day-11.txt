Set Operators
_____________
union ---------> combines result from two queries and removes duplicate rows, columns must have the same number and type

union all -----> combines results from two queries and includes all rows, including duplicates, column must have the same number and type

intersect ------> returns rows that are common to both queries, columns must have the same number and type

except ----------> returns rows from the first query that are not present in the second query, columns must have the same number and type


JOINS
______
Inner join --> matched records from both tables
Left Join --> matched records tables + left table records
right join --> matched records tables + right table records
full join --> inner join + right join + left join
cross join --> it performs cartesian product
